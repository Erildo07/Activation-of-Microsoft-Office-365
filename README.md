Execução do Script
Pré-requisitos

Sistema operacional Windows compatível

Permissões de Administrador na máquina

Acesso ao diretório onde o arquivo script.bat está armazenado

Procedimento

Abra o Prompt de Comando com privilégios administrativos:

Clique no menu Iniciar

Pesquise por cmd

Selecione Executar como administrador

Navegue até o diretório onde o script está localizado:

cd C:\caminho\para\diretorio  


Execute o script com o seguinte comando:

script.bat  

Execução Alternativa

Também é possível executar o script diretamente pelo Explorador de Arquivos:

Clique com o botão direito sobre script.bat

Selecione Executar como administrador

Observações Importantes

Certifique-se de que possui as permissões adequadas antes da execução.

Recomenda-se validar o conteúdo do script antes de executá-lo em ambiente de produção.

Em ambientes corporativos, siga as políticas internas de segurança e conformidade.
